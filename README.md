A compact deterministic chess engine in 4 KB of Python: 0x88 board, alpha-beta search with quiescence, a transposition table, killer moves and piece-square evaluation, searching to a fixed node budget, never a clock.

## Run it

```sh
MAKEFUN_ENV_URL=<trial env url> python3 main.py
```
